# Frontend – TTDH Automation

Interfaz web (dashboard y pantallas de la plataforma) desarrollada con **React + Vite**.

```bash
npm install      # instalar dependencias
npm run dev      # servidor de desarrollo en http://localhost:5173
npm run lint     # revisar el código
npm run build    # compilar para producción (carpeta dist/)
```

En desarrollo, las llamadas a `/api` se redirigen al backend FastAPI en `http://localhost:8000` (ver `vite.config.js`).
