# Evidencias de sistema – TTDH Automation

| Carpeta | Contenido |
|---------|-----------|
| `Aplicación/backend/` | API REST en Python + FastAPI, conexión a SQL Server y un paquete por módulo (recepción, extracción OCR, ETL, validaciones, cruce, trazabilidad, IA y reportes). |
| `Aplicación/frontend/` | Interfaz web en React + Vite (dashboard y pantallas de la plataforma). |
| `Aplicación/data/` | Datos y documentos simulados para pruebas. Nunca datos reales. |
| `Base de datos/` | Scripts de SQL Server que implementan el Modelo Entidad-Relación: creación de la base, tablas con llaves y restricciones, bitácora inalterable (RF10) y datos iniciales (roles RF09). |

Las instrucciones de instalación y ejecución están en el `README.md` de la raíz del repositorio.
